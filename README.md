### Opção 1: Publicação Direta via GitHub (Recomendado)

1. **Envie o código para o seu repositório no GitHub:**
   ```bash
   git init
   git add .
   git commit -m "feat: landing page Redação LGPD pronta para produção"
   git branch -M main
   git remote add origin https://github.com/SEU-USUARIO/redacao-lgpd.git
   git push -u origin main
   ```

2. **No painel da Vercel ([vercel.com](https://vercel.com)):**
   - Clique em **"Add New..."** > **"Project"**.
   - Selecione o repositório **redacao-lgpd** que acabou de subir.
   - A Vercel detectará automaticamente o framework como **Vite**:
     - **Framework Preset**: `Vite`
     - **Build Command**: `npm run build`
     - **Output Directory**: `dist`
     - **Install Command**: `npm install --legacy-peer-deps` (já configurado no vercel.json e .npmrc automaticamente)
   - Clique em **"Deploy"**.

3. Em menos de 1 minuto seu site estará online com HTTPS gratuito e CDN global! 🎉

---

### Opção 2: Publicação via Terminal (Vercel CLI)

Se preferir publicar diretamente pelo terminal do seu computador:

1. Instale a Vercel CLI globalmente (se ainda não tiver):
   ```bash
   npm i -g vercel
   ```

2. Na pasta raiz do projeto, execute:
   ```bash
   vercel
   ```
   - Responda às perguntas padrão (pressione Enter para aceitar as configurações automáticas já definidas no `vercel.json`).

3. Para publicar diretamente em produção:
   ```bash
   vercel --prod
   ```
